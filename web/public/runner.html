__MARCA__ Runner

Let your assistant run commands on your machine (the computer in front of you), even behind a home network. You install a small program that dials into __MARCA__; nothing opens a port on your computer.

__MARCA__ Runner is not verified by Apple or Microsoft yet, so your system will show a security warning.

1. Get your connection code

This code links the app to your account. It appears only once; keep this tab open, you will paste it into the app in a moment.

Keep this code to yourself. It grants execution access to your machine while the app is open. If it leaks, revoke it in your codes below.

2. Download and open the app

Download the __MARCA__ Runner app and open it. It opens a window in your browser for you to paste the code; no terminal or commands needed. After that, just leave it running.

Download for Mac Download for Windows
Other system or advanced mode (command line)
Mac CLI (Apple Silicon) Mac CLI (Intel) Linux CLI

CLI mode expects the code in __RUNNERENV___TOKEN and runs in the terminal (without opening the panel). Set the starting folder with __RUNNERENV___DIR=~/folder.

3. Paste the code into the panel

When you open the app, a browser tab shows the __MARCA__ Runner panel. Paste the code from step 1 there and click Connect. The indicator above turns green once it connects. Done: you can close the tab, it keeps running (to stop it, use Quit in the panel).

4. Ask your assistant

With the app green above, just ask in the chat, for example: “run hostname; whoami; pwd on my machine”. The one operating the machine is the assistant shown in the status above; to switch, go to Connections → __MARCA__ Runner. A group assistant cannot operate the Runner (a group is a channel with several people, the Runner is your machine).

__MARCA__ · the runner runs commands only while you keep it open.
