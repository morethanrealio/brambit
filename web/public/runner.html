__MARCA__ Runner

Deixe seu assistente rodar comandos na sua máquina (o computador na sua frente), mesmo atrás de rede doméstica. Você instala um programinha que disca pro __MARCA__; nada abre porta no seu computador.

O __MARCA__ Runner ainda não está verificado pela Apple ou Microsoft, por isso o sistema vai dar um alerta de segurança.

1. Pegue seu código de conexão

Esse código liga o app à sua conta. Ele aparece uma única vez; deixe esta aba aberta, você vai colá-lo no app daqui a pouco.

Guarde este código só pra você. Ele dá acesso de execução à sua máquina enquanto o app estiver aberto. Se vazar, revogue em seus códigos abaixo.

2. Baixe e abra o app

Baixe o app do __MARCA__ Runner e abra. Ele abre uma janela no seu navegador pra você colar o código; não precisa de terminal nem comando. Depois é só deixar rodando.

Baixar para Mac Baixar para Windows
Outro sistema ou modo avançado (linha de comando)
Mac CLI (Apple Silicon) Mac CLI (Intel) Linux CLI

O modo CLI espera o código em __RUNNERENV___TOKEN e roda no terminal (sem abrir o painel). Fixe a pasta inicial com __RUNNERENV___DIR=~/pasta.

3. Cole o código no painel

Ao abrir o app, uma aba do navegador mostra o painel do __MARCA__ Runner. Cole ali o código do passo 1 e clique Conectar. O indicador acima fica verde quando conectar. Pronto: pode fechar a aba, ele continua rodando (pra parar, use Encerrar no painel).

4. Peça pro seu assistente

Com o app verde acima, é só pedir no chat, por exemplo: "roda hostname; whoami; pwd na minha máquina". Quem opera a máquina é o assistente que aparece no status acima; pra trocar, vá em Conexões → __MARCA__ Runner. Assistente de grupo não pode operar o Runner (grupo é canal com várias pessoas, o Runner é a sua máquina).
