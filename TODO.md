Open work on Brambit lives in
[GitHub issues](https://github.com/morethanrealio/brambit/issues). Each issue
says what is wrong or missing, why it matters and where to start reading.

Labels that help you pick:

- [`good first issue`](https://github.com/morethanrealio/brambit/labels/good%20first%20issue):
  self-contained, with a clear place to start.
- [`needs design`](https://github.com/morethanrealio/brambit/labels/needs%20design):
  post a proposal in the issue before writing code.
- [`maintainer decision`](https://github.com/morethanrealio/brambit/labels/maintainer%20decision):
  waiting on a decision; don't start yet.
- [`translation`](https://github.com/morethanrealio/brambit/labels/translation):
  text in the wrong language, read by the model or by a person.

Want to take an issue? Follow [CONTRIBUTING.md](CONTRIBUTING.md): comment on it
before writing code, so two people don't do the same work. Found new work? Open
an issue.
